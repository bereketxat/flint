# FLInt (Frame Literal Interpreter v2026.11.14)

A simple interpreter-like tool to parse through a file and execute a few commands for a custom language. 

## Features
- Supports keywords: `print`, `repeat` and `add`. 
- See the outputs immediately in your terminal. 
- Check the `version`, get `help` and create a `new` template file. 

## How to Run

```bash
# Compile the program
gcc flint.c -o flint

# Create a template file
./flint new

# Run the file
./flint run main.fme
```
